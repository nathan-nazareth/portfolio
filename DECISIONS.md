### Portfolio site — shipped 2026-11-26

| Decision | Choice |
|---|---|
| Stack | **Plain TypeScript, no framework.** Static HTML generated by a script. |
| Hosting | **Cloudflare Workers static assets** (`portfolio.n8-nazareth.workers.dev`). Chosen over Vercel — the other site already lives on Cloudflare, and a redirect shim is a wart worth not repeating. |
| Layout | `src/packages/projects` holds the data, `src/packages/site` renders it, `scripts/build-site.ts` writes `dist/`. `wrangler.jsonc` runs the build and ships `dist/` as Worker assets, so a push is a deploy. |
| Pages | An index, one page per project, and a 404. |
| Copy | Written from the repos themselves — what each thing is and how it is built. |
| Contact | GitHub profile only, linked from the header and the footer. No form, no email on the page. |
| Visual direction | Dark, editorial, serif display with monospace metadata. System fonts only, no third-party requests. |
| Domain | `portfolio.n8-nazareth.workers.dev` for now. A custom domain is still open. |
